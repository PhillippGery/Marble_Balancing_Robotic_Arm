TECHNICAL DETAILS
================================================================================

Atomic Reset Flow:
─────────────────
  reset() 
    → _reset_until_landed(attempt=0)
      ├─ Publish zero twist (TCP brake)
      ├─ Zero all state & velocities
      ├─ _delete_marble() [waits for odom silence]
      ├─ _home_arm() 
      ├─ _spawn_marble()
      ├─ Wait for landing (20 s deadline)
      ├─ If landed: start servo, init phi_old, return obs ✓
      └─ If not landed: _reset_until_landed(attempt+1) [retry loop]
    
    On 10th failure: RuntimeError("Marble spawn permanently failed")

Ghost Detection Flow:
──────────────────
  step()
    ├─ Extract marble position (x, y)
    ├─ If |x| < 1e-6 AND |y| < 1e-6:
    │   ├─ _zero_position_count += 1
    │   └─ If _zero_position_count >= 5:
    │       ├─ Log: "GHOST MARBLE DETECTED"
    │       ├─ reward -= 100.0
    │       └─ terminated = True
    └─ Else: _zero_position_count = 0

Reward Lockout Flow:
───────────────────
  step()
    ├─ Check: if not self._landed
    │   ├─ reward = -100.0
    │   ├─ terminated = True
    │   ├─ Log warning
    │   └─ Return early [obs, -100.0, True, True, {}]
    └─ [Continue normal step if landed]
