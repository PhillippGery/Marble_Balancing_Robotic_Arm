═════════════════════════════════════════════════════════════════════════════
ALL COMMAND-LINE OPTIONS
═════════════════════════════════════════════════════════════════════════════

--timesteps STEPS          Total training steps (default 500000)
                           Examples: 10000, 100000, 1000000

--stage STAGE              Starting curriculum stage (default 0)
                           Values: 0, 1, 2
                           Stage 0: λ=5°/s (tight control)
                           Stage 1: λ=10°/s (medium control)
                           Stage 2: λ=15°/s (loose, harder)

--seed-steps STEPS         RLPD pre-seeding steps (default 20000)
                           Set to 0 when continuing training
                           Higher = more LQR data before RL learns

--load PATH               Path to existing model to continue
                          Example: models_td3_v2/best_model_td3_v2.zip

--use-ekf                 Use EKF state instead of EMA
                          (adds --use-ekf flag, no value needed)

--tcp-lissajous true/false Enable TCP Lissajous disturbance (default false)
                           true  = 50% Lissajous + 50% Random Walk
                           false = stationary TCP (easier)

--spawn-radius RADIUS     Random spawn radius (default 0.0 = always center)
                          0.0  = marble always spawns at center
                          0.12 = marble spawns within 12cm of center (harder)

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

ERROR: "ModuleNotFoundError: No module named 'gazebo_rl_env_v2'"
FIX:   cd src/marble_balancer/rl_training (run from correct directory)

ERROR: "Gazebo not responding" or "Connection refused"
FIX:   Launch Gazebo in separate terminal first (training auto-waits)

ERROR: "Training very slow" (10% expected speed)
FIX:   Ensure Gazebo launched with gui:=false

ERROR: "TensorBoard shows no data"
FIX:   Wait 10-20 sec, refresh browser (F5), check directory exists

ERROR: "Out of memory" (especially on CPU)
FIX:   Reduce --timesteps or increase --seed-steps
